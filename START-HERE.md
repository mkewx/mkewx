# MKEWX GitHub Pages Package (Jekyll) — Start Here

This folder is a complete, copy‑paste starter for **MKEWX.com**:
- A terminal‑style homepage that lists your latest dispatches (stories)
- A “READER” that loads a dispatch inline when you click it
- A radar scope you can toggle with the `RADAR` command
- RSS feed at `/feed.xml`

## Quick preview (no installs)
Open **demo.html** in your browser.  
This is a standalone “what it should look like” demo.

## Deploy to GitHub Pages (beginner-friendly)
Follow `DEPLOY-GITHUB-PAGES.md`.

## Writing dispatches (your main workflow)
Follow `WRITING-DISPATCHES.md`.

See `SCHEDULED-PUBLISHING.md`.
